FAQ

Questions leaders ask.

Do I need my own API key?

No. The platform key covers a daily token allowance. Add your own key in Settings to go beyond it.

How fast is approval?

Instant when auto-approval is on. In review mode, requests are decided within 24 hours and overdue ones are flagged.

Can the SQL agent change data?

No. It can only run a single SELECT, capped at 200 rows and 5 seconds, on a read-only sample database.

Is my input stored?

Run metadata (tokens, cost, latency, status) is stored for analytics. Prompt bodies are not logged.
